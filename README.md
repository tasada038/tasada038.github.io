# tasada038.github.io

This page is the author's homepage.

# Usage

## local view
```sh
cd ~/GithubPage/tasada038.github.io
hugo server
```

## Main content

```sh
cd ~/GithubPage/tasada038.github.io/content
```

## Authors Bio

```sh
cd ~/GithubPage/tasada038.github.io/data/authors/
```

## Icons

```sh
cd ~/GithubPage/tasada038.github.io/assets/media/
```

## Uses Academic-project-page-template
If you uses academic-project-page-template, please setting bellow.

```
Settings > Pages > GitHub Pages / Branch
master /root
```
